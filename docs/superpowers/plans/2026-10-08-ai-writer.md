# AI Writer Implementation Plan

> **For agentic workers:** This plan is being executed natively in this session as requested by the user. Steps use checkbox syntax for tracking.

**Goal:** Build a private, local Chrome MV3 AI writing extension with selection-based rewriting through OpenRouter.

**Architecture:** React popup stores settings in `chrome.storage.local`. A content script detects selections and owns a transient shadow-DOM floating interface. It preserves a generic editor bookmark for precise replacement and sends text/mode requests to a service worker, which loads the key and delegates to an `AIProvider` implementation.

**Tech Stack:** TypeScript, React, Vite, Chrome Manifest V3, Vitest, OpenRouter API.

**Spec:** User-approved requirements in the conversation dated 2026-10-08.

## Global Constraints

- Use `openrouter/free` by default.
- Keep the OpenRouter API key out of source and logs; persist it only in `chrome.storage.local`.
- Request only `storage` and page host access needed for content scripts.
- No backend, database, authentication, billing, or cloud service.
- Support textarea, text/search inputs, and contenteditable elements.

## Review Focus

- Selection lost during menu interaction: preserve a bookmark and verify targeted replacement.
- Unsupported or empty selection: avoid sending requests and show useful feedback.
- Provider failures and malformed responses: map to human-readable errors.
- Vite output names and manifest paths: ensure all MV3 resources resolve in `dist`.
- Popup settings persistence: verify a saved key/model can be read by the service worker.
